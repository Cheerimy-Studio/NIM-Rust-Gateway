## 计费

后台“模型接入 → 模型定价”支持按次和按 token。数值价格仍表示元/次，兼容已有配置。

按 token 规则例子：

```json
{"mode":"token","input":2,"output":8,"tiers":[{"min_input":128001,"input":4,"output":16}]}
```

输入、输出单价均为元/百万 token。`min_input` 是含该值的输入起点；取已满足的最大起点，整次输入和输出使用该档单价，不采用分段累进计算。档位按起点递增，最多 16 档。

- 输入 100000、输出 1000：`100000×2/1000000 + 1000×8/1000000 = ¥0.208`。
- 输入 128001、输出 1000：命中第二档，费用 `¥0.528004`。
- 账本精度为六位小数，正费用最小结算 ¥0.000001。
- 优先使用上游 usage；上游缺失时沿用网关的用量估算，不保证与模型原生分词器完全一致。缓存 token 暂按普通输入单价计算。
- 请求发送前按实际渠道价格、估算输入及请求输出上限预占额度；未声明输出上限时暂用 1024 估算。成功按实际用量结算，失败和取消释放预占。
- 预占保存在当前进程内，适用于本项目单进程 JSON 存储。输出超出预估、价格档位因实际输入变化或进程重启时仍可能出现有流水记录的欠款；这不是跨实例分布式额度系统。
- 每次请求保存价格快照，进行中修改价格不影响该请求。流式模型路由按实际成员计费，避免按路由名查不到价格而漏扣。
- Chat、Responses、Messages 的流式与非流式使用同一结算函数。Embedding 不预占输出费用。未完成流、上游失败和用户取消沿用仅成功计费口径。
- 免费/付费专用 Key 的路由可见性按可达成员判断。WebClaw 复用全模型 Key，避免误拿免费专用 Key 导致付费模型无法使用。

用户流程参考 New-API 的账户、令牌、模型价格与日志组织；未实现完整 New-API API、数据库、倍率表达式、订阅或插件兼容。

## WebClaw 浏览器 Agent

打开 WebClaw，勾选“启用本地工具”，可使用模型的 function tools 自动完成多轮任务。

- 工具：列出文件、读取 UTF-8 文件、创建或替换文件；支持流式与非流式工具调用。
- 添加文本文件后，Agent 可按需读取；生成文件保存在浏览器工作区，点击文件名下载。项目导入/导出包含这些文件与工具历史。
- 支持 File System Access API 的浏览器可连接本机目录。每次写入都显示路径和内容预览，由用户确认；默认焦点在取消。停止会取消尚未确认的写入。
- 不支持目录 API 的浏览器可使用添加文件和下载文件。目录权限句柄不写入项目文件，刷新后需要重新连接。
- 每任务最多 8 次模型请求，每次最多 16 个工具调用；单文件最多 256 KiB、浏览器工作区最多 64 文件和 2 MiB。项目对话另有条数和长度上限。
- 工具拒绝绝对路径、路径穿越、任意命令。未加入系统 Shell、后台服务或远程执行节点。
- 项目、Agent 执行和文件操作留在当前浏览器；模型推理仍通过所选网关/上游完成，读取的文件内容可能随工具结果发送给模型。请求携带跳过训练采集标记；网关和上游的请求处理仍按各自部署设置执行。
- 这不等于完全离线推理。要让推理也留在本机，需将渠道指向本机模型服务。
- 本机浏览器存储有配额；清理站点数据会删除项目，请用导出备份。切换、删除、导入项目时需先停止任务，避免旧任务继续修改文件。
